# Over9kFPV

Link page for Over9kFPV, live at https://over9kfpv.github.io.

A single static `index.html` with inline CSS and no build step. It links to:

- [Stickbeats](https://over9kfpv.github.io/stickbeats/): sound themes and voice packs for EdgeTX radios
- [Whoopshop](https://github.com/Over9kfpv/whoopshop): AI-assisted Tiny Whoop workshop
- [Whooplog](https://over9kfpv.github.io/whooplog/): 1S tinywhoop build spec, rates, blackbox workflow and flight log
- [Betaflight skill](https://github.com/Over9kfpv/betaflight-skill): agent skill for Betaflight
- [YouTube](https://www.youtube.com/@Over9Kfpv)
- [Instagram](https://www.instagram.com/over9k.fpv/)

## Local preview

Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy

Pushes to `main` are published by GitHub Pages.
